# DigiDOT Technical Documentation

Welcome to the technical documentation for DigiDOT.

This site contains specifications, integration guidelines and technical documentation intended for EHR vendors and other parties integrating with DigiDOT services.

## EPJ integration

The initial scope of this documentation covers the integration between Electronic Health Record (EHR) systems and the DigiDOT shared storage services.

Documentation will include:

- Architecture and integration principles
- Authentication and authorization
- Network and connectivity requirements
- API specifications
- Data models and standards
- Security requirements
- Implementation guidelines
