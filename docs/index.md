# DigiDOT Technical Documentation

Welcome to the technical documentation for **DigiDOT**.

This documentation provides technical specifications and implementation guidance for vendors and other parties integrating with DigiDOT services.

## About DigiDOT

DigiDOT is establishing common digital services and infrastructure for the public dental health service in Norway.

This documentation initially focuses on the interfaces between **Electronic Patient Record (EPJ) systems** and the **DigiDOT shared storage services**.
