# Documentation timeline

DigiDOT will publish documentation of the central storage solution and its integration points in stages. The first documentation package is planned by **1 November 2026**, with the complete central storage EHR documentation package planned by **1 March 2027**.

Technical documentation, implementation guidance, API references and supporting resources will be released progressively as individual services become ready for exploration.

## Planned release windows

The timeline below outlines when EHR suppliers can expect each documentation topic to become available.

| Planned release | Documentation topics |
| :--- | :--- |
| **October 2026** | Architecture and included services: overall description<br>FHIR profiles and implementation guide |
| **November 2026** | Master Patient Index integration<br>Authentication and authorisation principles |
| **December 2026** | Dental server<br>Validation<br>Error examples<br>Terminology service |
| **January 2027** | Restrictions service<br>Audit service |
| **February 2027** | Test onboarding<br>Test scenarios and test data<br>Examples |
| **March 2027** | Known issues<br>Corrections after the internal test period<br>Release plan |

## Documentation and service readiness

> **Documentation availability does not imply production readiness.**
>
> Environment availability and service readiness will be stated separately. The March milestone is the complete documentation baseline for the agreed Stage 1 scope, followed by verification updates through **31 March 2027**.
