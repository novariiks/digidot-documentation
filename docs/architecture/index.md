# Architecture

The main goal of the DigiDOT project is to establish a common digital EHR service with a common shared infrastructure and data foundation for the public dental health service in Norway.

This section documents all aspects of the architecture relevant to suppliers and vendors working with the common dental service in Norway and covers among others integrating Electronic Health Record (EHR) systems with the common storage solution.
